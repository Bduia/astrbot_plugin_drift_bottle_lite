# 🌊 AstrBot 跨群漂流瓶插件 (Drift Bottle Lite)

一个轻量级、带隐私保护的 AstrBot 跨群盲盒聊天插件。不依赖复杂数据库，纯 JSON 存储，绝对不报错！

## ✨ 功能特色
- **匿名漂流**：扔瓶子不暴露身份，随机分配水果代号（如：一只水母、深海巨兽）。
- **隐私保护**：群号自动脱敏，随机分配海域名称（如：东海龙宫、花果山）。
- **完整旅程**：每个瓶子记录投出与被捞的完整轨迹。
- **沉没机制**：瓶子有寿命（默认72小时）和被捞上限（默认3次）。
- **防刷屏**：个人扔瓶冷却限制、敏感词拦截。
- **定时清理**：后台每分钟检查过期瓶子并自动沉没。

## 🎮 指令列表
- `/扔瓶 [内容]`：将内容装进瓶子，随机漂向机器人的另一个群。
- `/捞瓶`：在当前群捞起一个漂流瓶，查看内容和旅程。
- `/漂流管理`：管理员指令（查看全服总数、强制沉没指定编号瓶子）。

## ⚙️ 配置项
在 AstrBot 后台插件配置界面可轻松修改：
- `bottle_max_length`: 瓶子字数限制
- `bottle_cooldown_seconds`: 个人冷却时间
- `bottle_nicknames`: 个人随机代号池（逗号分隔）
- `group_nicknames`: 群聊随机代号池（逗号分隔）
- `bottle_group_whitelist`: 参与群白名单
- `bottle_admin_ids`: 管理员QQ号

## 🚀 安装方法
1. 将本仓库克隆或下载到 AstrBot 的 `data/plugins/` 目录下。
2. 重启 AstrBot 即可自动加载。
